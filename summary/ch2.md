# 第二章 货币

> 覆盖范围：印刷页 53—69（PDF 73—89 页）｜已读页数：17/17

## 一、整体逻辑（3—5 句）

第二章是全书的第二章，承接第一章商品经济（含劳动二重性、价值规律）的内容，主干是：先从价值形式的演化（简单→扩大→一般→货币形式）说明货币的起源与本质，再展开货币的五大职能（价值尺度、流通手段为基本职能，由此派生出贮藏手段、支付手段、世界货币），接着进入第二版新增的"货币的形式"（金属货币→纸币→信用货币的演化，及 IMF/我国的货币层次划分 M0—M3、M0—M2），最后落到第三节的货币流通量规律：金属货币流通量规律 → 纸币和信用货币流通量规律 → 通货膨胀与通货紧缩。贯穿全章的核心命题是：货币是商品生产者之间社会生产关系的体现，因而货币投放必须遵循货币流通量规律，以防通胀通缩。本章末尾（印刷页 69）附有 5 道思考题，可直接作为复习自测的锚点。

## 二、知识点树

**第一节 货币的本质和职能**

*一、货币的起源和本质*

- **简单的、个别的或偶然的价值形式**：人类最初是原始社会后期部落之间偶然进行的剩余产品交换，"1 只绵羊 = 2 把斧子"；这种交换实质是产品交换而非真正的商品交换。
- **相对价值形式与等价形式**：等式左边的绵羊处于主动地位，是相对价值形式；右边的斧子处于被动地位，是等价形式。一切价值形式都是由这两个既对立又统一的方面构成的。
- **等价形式的三个特征**：第一，使用价值成为价值的表现形式；第二，具体劳动成为抽象劳动的表现形式；第三，私人劳动成为直接形式的社会劳动。
- **总和的或扩大的价值形式**：一种商品与一系列商品相交换，价值量获得更充分的表现；但商品价值的表现缺乏共同标准，因而产生了交换的困难。
- **一般价值形式与一般等价物**：一般价值形式是扩大的价值形式颠倒了的形态；一切商品的价值都表现在同一种商品上，商品价值的表现因而统一，充当一般等价物的商品即在一定程度上起到货币的作用。
- **货币形式**：一般价值形式的进一步发展，是价值形式的完成形态，即固定地充当一般等价物的特殊商品；金银因自然属性最适合充当货币材料，故在很长历史时期内充当真正意义上的货币。
- **货币的本质**：货币作为从商品世界中游离出来固定地充当一般等价物的特殊商品，成为社会劳动的化身，具有与所有商品相交换的能力，成为社会财富的一般代表，体现了商品生产者之间的社会生产关系。

*二、货币的职能*

- **价值尺度与价格标准**：价值尺度是货币表现、衡量、计算商品价值大小的尺度，执行这一职能只需观念上或想象中的货币；商品价值表现在货币上即成为价格，因此价格是商品价值的货币表现。价格标准是为执行价值尺度职能派生出来的技术规定，最初与货币商品的实际重量单位一致（中国古代"两"、英国"英镑"原为重 1 磅的银币名称），后来因贵金属数量不足和国际间货币流通，最终出现完全不包含实际重量的货币单位或价格标准（人民币以"元、角、分"为价格标准）。
- **流通手段**：货币充当商品交换媒介；此时需要的是现实存在的货币；商品流通公式为 W—G—W（商品—货币—商品），买和卖在时间与空间上分离，卖的完成即 W—G 带有决定性意义，马克思称之为"危险的跳跃"。
- **贮藏手段**：商品所有者卖出商品并持有货币后不立即购买，货币退出流通领域，作为社会财富的一般代表被贮藏保值；在金属货币条件下起调节流通中货币量的"蓄水池"作用，在纸币制度条件下因纸币本身没有价值而丧失这一作用。
- **支付手段**：货币用于清偿债务或支付赋税、租金、利息、工资等，最初由商品的赊购赊销引起；发挥这一职能须满足三个条件：货币购买力不降低、买者应支付一定数量的利息、确保到期偿还债务。
- **世界货币**：货币在世界市场充当一般等价物，是货币国内职能在国际范围的延伸；国际支付手段、购买手段和社会财富的一般代表；必须以足值的金或银充当，美元、欧元等在一定范围内和程度上起世界货币作用。

**第二节 货币的形式**

*一、货币形式的演化*

- **金属货币**：货币的最初形式，经历自然条块金属货币 → 私人铸币 → 国家铸币 → 辅币的演化；印记主要包括形状、花纹、文字（如中国古代的布币、刀币、圆钱）。
- **纸币**：由国家发行并依靠国家权力强制发挥货币职能的纸质货币；本身没有价值或其价值可以忽略不计；之所以能被社会普遍接受，靠的是国家的强制力量和信誉；在执行流通手段和支付手段职能时起价值符号的作用。
- **信用货币**：主要包括银行券、支票存款、电子货币；银行券最初作为代用货币出现，20 世纪 30 年代世界经济危机后各国先后停止可兑换性而纸币化；电子货币严格说并不是一种新的货币，只是传统货币电子化的存在形式。

*二、货币层次*

- **货币层次的划分依据**：各国划分方法多种，但大都以流动性的大小为依据，即以某种资产转换为现金或支票存款的能力作为标准；国际货币基金组织《货币与金融统计手册》与我国均作分层划分。
- **IMF 的 M0—M3**：M0 为现金，即本市流通中的现金；M1 为狭义货币 M0 + 可转让本币存款和在国内可直接支付的外币存款；M2 为狭义货币和准货币，即 M1 + 一定期限（三个月到一年之间）的单位定期存款和储蓄存款 + 外汇存款 + 大额可转让定期存单；M3 为广义货币 M2 + 外汇定期存款 + 商业票据 + 互助金存款 + 旅行支票。
- **我国的货币层次**：M0 为本市流通中的现金；M1 为狭义货币 M0 + 能开支票进行支付的单位活期存款；M2 为广义货币 M1 + 准货币（居民储蓄存款 + 单位定期存款 + 信托存款、委托存款、财政预算外存款、证券公司客户保证金等其他存款）。

**第三节 货币流通量及其规律**

*一、货币流通量*

- **货币流通与货币流通量规律**：货币流通是指货币不断地作为流通手段和支付手段在买者和卖者之间运动；货币流通量规律即货币流通同商品流通相适应的规律，其基本要求是流通中的货币量必须满足商品流通的需要。
- **影响流通中所需货币量的因素**：货币作为流通手段，其数量由全部商品价格总额和货币流通速度两个因素决定；贮藏手段职能使流通中货币过多时退出流通、不足时投入流通；支付手段职能则使货币流通量公式中加入赊销、到期支付与互相抵消等修正项。

*二、纸币和信用货币流通量*

- **纸币和信用货币流通量规律**：纸币流通量规律以金属货币流通量规律为基础，纸币发行量必须限于流通中所需要的金属货币量，流通纸币总量必须同它所代表的金属货币流通量相等；信用货币流通量规律与纸币相同，供给量只限于它象征性地代表流通中货币的需求量。

*三、通货膨胀和通货紧缩*

- **通货膨胀、通货紧缩与支付危机**：通货膨胀指由于货币发行量超过流通中实际需要的货币量而引起的物价总水平持续上涨的经济现象；相反则可能出现通货紧缩，即一般物价水平持续下降的经济现象；信用货币流通还可能产生支付危机，严重时引起经济和社会的动荡。

## 三、核心论断与必背表述

1. 货币是人类社会生产发展到一定阶段的产物，是商品以及交换价值本身不断发展的结果。（p53）
2. 马克思指出，"金银天然不是货币，但货币天然是金银"；黄金或白银成为货币，完全是商品生产和商品交换发展到一定阶段的自然结果。（p57）
3. 货币的出现克服了物物交换的困难，推动了商品交换的发展，也使得商品世界分裂为对立的两极：一极是具有各种特殊使用价值的商品，另一极是表示商品价值的货币。（p57）
4. 货币商品成为社会劳动的化身，具有与所有商品相交换的能力，成为社会财富的一般代表；这就是货币的本质。（p58）
5. 货币的本质是通过它的职能来实现或者表现出来的；其中价值尺度和流通手段是最基本的职能，货币首先是作为这两个职能的统一而出现并发挥作用的。（p58）
6. 商品价格与商品价值成正比，与货币价值成反比；商品价格的高低，既取决于商品价值的变动，又取决于货币价值的变动。（p59）
7. 货币作为流通手段改变了商品交换的形式，使直接的物物交换发展为商品流通；马克思称 W—G 的实现为"危险的跳跃"——"这个跳跃如果不成功，摔坏的不是商品，但一定是商品占有者"。（p60）
8. 货币流通量规律即"流通手段量决定于流通商品的价格总额和货币流通的平均速度这一规律"。（p66，引自《马克思恩格斯文集》第 5 卷，人民出版社 2009 年版，第 145 页）
9. 纸币的发行限于它象征地代表的金（或银）的实际流通的数量；纸币发行的原则是：纸币发行量必须限于流通中所需要的金属货币量。（p67）
10. 西方经济学界流行的货币数量论虽然认为通货膨胀（紧缩）的主要原因是货币发行过多（过少），但并没有提出货币发行过多或过少的标准；"货币数量论反映的只是货币流通的表面现象，并没有阐明货币流通的本质"。（p68）

## 四、公式与量化关系

**1. 货币的五种职能（按教材 p58 的表述与顺序）**

价值尺度 → 流通手段 → 贮藏手段 → 支付手段 → 世界货币。其中价值尺度和流通手段是最基本的职能，在此基础上产生了贮藏手段、支付手段和世界货币等职能（p62）。

**2. 价值形式的四个等式（p53—57）**

**3. 货币流通量基本公式（p65—66）**

```
一定时期内流通中需要的货币量 = 流通中商品价格总额 / 同一货币单位的平均流通速度（次数）
```

- 变量含义：**流通中商品价格总额** = 各种商品数量与各自价格的乘积之和（p65）；**货币流通速度** = 一定时期内同一货币单位的平均周转次数（p66）；**一定时期内流通中需要的货币量** = 该时期商品流通与支付所需要的货币量。
- 方向关系：一定时期内商品流通所需要的货币量，同商品的价格总额成正比例，而同货币流通速度成反比例（p66）。
- 教材算例：一定时期（假定一年）内社会所需实现的商品价格总额是 400 亿元，假定每 1 元货币平均在一年内流通 10 次，则只要有 40 亿元（400 亿元 ÷ 10）的货币，就足够实现 400 亿元商品的交换（p66）。
- 马克思表述：流通手段量决定于流通商品的价格总额和货币流通的平均速度这一规律（p66）。

**4. 计入贮藏手段与支付手段职能后的修正公式（p66）**

```
                            流通中商品  - 赊销商品   + 到期支   - 互相抵消
一定时期内流通中需要的货币量 = 价格总额     价格总额      付总额     支付总额
                            ------------------------------------------
                            同一货币单位的平均流通速度（次数）
```

- 变量含义：**赊销商品价格总额** = 当期赊购赊销而不需立即支付货币的商品价格；**到期支付总额** = 到期需以货币偿付的债务总额；**互相抵消支付总额** = 各当事人之间债权债务可以相互抵消而无需实际支付的部分。
- 方向关系：流通中货币需求量同到期需要支付的总额呈同方向变化，同赊销商品价格总额和互相抵消的支付总额呈反方向变化（p66）。

**5. 纸币流通量的核心公式（p67）**

```
单位纸币所代表的金属货币量 = 流通中所需要的金属货币量 / 流通中的纸币总额
```

- 变量含义：**单位纸币所代表的金属货币量** = 一张（单位）纸币实际代表的金（或银）数量；**流通中所需要的金属货币量** = 由流通中商品价格总额与货币流通速度决定；**流通中的纸币总额** = 市场上纸币总量。
- 教材算例：若流通中货币需求量是 10 亿元金币，但纸币发行额是 20 亿元，那么 1 元纸币就只能代表 0.5 元金币进行流通（p67）。
- 发行原则：纸币发行量必须限于流通中所需要的金属货币量；纸币所代表的价值同它发行的数量成反比（p67）。

**6. 信用货币流通量关系（p67—68）**

- 信用货币的流通量只限于它象征性地代表流通中货币的需求量；供给量大于需求量则信用货币贬值、物价上涨导致通货膨胀；供给量小于需求量则信用货币升值、物价下降导致通货紧缩。
- 信用货币的投放必须以货币流通量规律为基础。

**7. 关于"实际货币流通量／名义货币流通量／所需货币流通量"**

- **存疑：这三个术语在本次阅读的印刷页 53—69 中均未出现**。教材在本章使用的是"一定时期内流通中需要的货币量""流通中所需要的金属货币量""流通中货币需求量""货币流通量"等表述。若复习资料中出现"实际/名义货币流通量"的说法，其来源可能不在本章，需另行核对。
- **存疑：教材未给出"纸币流通量 = 商品价格总额 / 纸币周转次数"这一公式**。教材关于纸币的量化关系是"单位纸币所代表的金属货币量 = 流通中所需要的金属货币量 / 流通中的纸币总额"，以及对纸币发行量的上限约束（"纸币的发行限于它象征地代表的金（或银）的实际流通的数量"），请勿与第 3 项基本公式混淆使用。

**8. 价值形式与货币流通相关的其他量化表述**

- 价格与价值的关系：商品价格与商品价值成正比，与货币价值成反比（p59）。
- 商品价格总额 = 各种商品数量和各自价格的乘积之和（p65）。
- 价格标准：最初与货币实际重量一致，后与实际重量分离（p59）。

## 五、逻辑链/因果链条

1. 剩余产品的偶然交换 → 简单价值形式 → 第一次社会大分工使交换经常化 → 总和（扩大）的价值形式 → 交换困难（缺乏共同标准） → 一般价值形式（一般等价物出现）→ 第二次社会大分工与真正商品生产 → 货币形式（金银固定充当一般等价物）。
2. 货币形式 → 货币本质（固定充当一般等价物的特殊商品，体现社会生产关系）→ 货币五大职能（价值尺度、流通手段为基本职能）→ 贮藏手段、支付手段、世界货币的派生。
3. 物物交换 → 商品流通（W—G—W）→ 买卖分离（"危险的跳跃"）→ 赊购赊销 → 延期支付 → 支付手段职能 → 支付链条 → 支付危机（生产危机与商业危机中的货币危机）。
4. 金属货币（自然条块 → 私人铸币 → 国家铸币 → 辅币）→ 金属货币流通量规律（贮藏手段自动调节的"蓄水池"机制）→ 纸币（价值符号，国家强制与信誉）→ 纸币流通量规律（发行量受金属货币需求量上限约束）→ 信用货币（银行券、支票存款、电子货币）→ 信用货币流通量规律 → 投放失控 → 通货膨胀或通货紧缩。
5. 贵金属供给不足 / 国际结算需要 → 纸币与信用货币取代金属货币 → 货币投放不再受金属量自动约束 → 必须以货币流通量规律为依据调节投放 → 防通胀通缩、保经济顺畅运行（p69）。
6. 商品价格总额 ↑ 或货币流通速度 ↓ → 所需货币量 ↑ → 纸币/信用货币超发 → 货币贬值 → 物价总水平持续上涨（通货膨胀）；反之则通货紧缩。

## 六、易混辨析

- **价值尺度 vs 流通手段 vs 支付手段**：价值尺度是"衡量"商品价值、执行时只需观念上的货币；流通手段是"媒介"商品交换、执行时需要现实存在的货币、买卖同时完成；支付手段是"清偿"债务与支付赋税租金利息工资等、来自赊购赊销且发生时间与商品交付分离。三者之中价值尺度与流通手段是基本职能。
- **贮藏手段 vs 支付手段**：贮藏手段是货币退出流通领域被保存起来（"货币退出流通领域"、执行时是"社会财富的一般代表"）；支付手段是货币仍在流通中用于清偿债务、支付赋税租金利息工资（"用于清偿债务或支付……"）。贮藏靠"退出流通"，支付靠"延后支付"。
- **相对价值形式 vs 等价形式**：相对价值形式在等式左边、处于主动地位（绵羊），其价值量通过交换得到相对表现；等价形式在等式右边、处于被动地位（斧子），以使用价值充当价值的表现形式。商品价值量在交换中只是得到相对的表现，而不是绝对的表现。
- **金属货币 vs 纸币 vs 信用货币**：金属货币本身有价值，其购买力与所包含金属的价值基本一致，流通量由贮藏手段自动调节；纸币本身没有价值或价值可忽略，靠国家强制力量和信誉被接受，在流通手段和支付手段中起价值符号作用，发行量必须限于流通中所需要的金属货币量；信用货币是依托银行信用的债务凭证（银行券、支票存款、电子货币），其流通量只限于象征性地代表流通中货币的需求量。
- **M0 / M1 / M2（及 M3）层次划分**：M0 为流通中的现金，是狭义货币的基础；M1 为狭义货币 = M0 + 可即时用于支付的存款（IMF：可转让本币存款和国内可直接支付的外币存款；我国：能开支票进行支付的单位活期存款）；M2 为广义货币 = M1 + 准货币（定期存款、储蓄存款等流动性较弱的资产；IMF 口径另加外汇存款、大额可转让定期存单，IMF 另有 M3 = M2 + 外汇定期存款、商业票据等）。划分标准是流动性大小而非数量多少。
- **货币流通量 vs 货币发行量**：货币流通量指在市场上实际处于流通领域、不断运动的货币量，由商品价格总额和货币流通速度决定；货币发行量指国家（银行）投放出去的货币数量。纸币发行量一旦超过流通中所需要的金属货币量，就会导致单位纸币代表的金属货币量减少、货币贬值、通货膨胀。
- **纸币流通量 vs 金属货币流通量**：金属货币流通量由贮藏手段的"蓄水池"机制自动调节，货币量与需求量趋于一致；纸币流通量不再自动调节，纸币一经国家强制发行即成为常量，必须靠发行量必须限于流通中所需要的金属货币量这一原则来约束，因而存在超额发行导致通胀的可能。
- **通货膨胀 vs 通货紧缩**：通货膨胀指由于货币发行量超过流通中实际需要的货币量而引起的物价总水平持续上涨的经济现象；通货紧缩指一般物价水平持续下降的经济现象。二者都是与货币相关的经济现象，本质上都是违背货币流通量规律的结果。
- **价值形式 vs 货币形式（价值形式的完成形态）**：价值形式是商品价值的表现形式；货币形式是一般价值形式的进一步发展，是价值形式的完成形态，二者唯一的区别在于一般等价物已经固定在黄金或白银等贵金属商品上。
- **价格标准 vs 价值尺度**：价值尺度是货币的职能；价格标准是为执行价值尺度职能派生出来的技术规定，随着贵金属数量不足和国际流通需要，价格标准最终与货币的实际重量逐渐分离开来。

## 七、可能的考察点

1. 货币的起源：价值形式由简单（个别、偶然）→ 总和（扩大）→ 一般 → 货币形式的演化过程及各阶段特征。
2. 相对价值形式与等价形式的关系，等价形式的三个特征。
3. 货币的本质：固定地充当一般等价物的特殊商品，体现商品生产者之间的社会生产关系。
4. 货币的五大职能及其相互关系（价值尺度与流通手段为基本职能，贮藏、支付、世界货币由此派生）。
5. 价格标准的含义、演变（从与实际重量一致到分离）及其作为技术规定的性质。
6. 流通手段与"危险的跳跃"：W—G—W 公式、买卖分离、危机可能性与现实性。
7. 贮藏手段的"蓄水池"作用及金属货币与纸币制度下的差别。
8. 支付手段的三个条件（购买力不降低、支付利息、确保到期偿还债务）与支付危机。
9. 世界货币的内涵与以足值金银充当的要求。
10. 货币形式的演化（金属货币 → 纸币 → 信用货币），含自然条块、私人铸币、国家铸币、辅币、银行券、支票存款、电子货币。
11. 货币层次的划分依据与 IMF M0—M3、中国 M0—M2 的口径。
12. 货币流通量规律的基本公式、修正公式与算例（400 亿元 ÷ 10 次 = 40 亿元）；纸币流通量规律与单位纸币代表金属货币量的公式（10 亿元需求 / 20 亿元发行 = 0.5 元）。
13. 通货膨胀与通货紧缩的定义、成因（违背货币流通量规律）及对经济运行的影响。
14. 教材思考题原题（p69）：①解释货币、纸币、通货膨胀、通货紧缩；②简述货币的起源和本质；③简述货币的职能；④简述货币形式的发展；⑤简述货币流通量规律的内容。
