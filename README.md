## 两处教材口径提醒

1. 第一章原文是「劳动生产率同商品的使用价值量成正比，同单位商品的价值量成**反比**」——流传较广的「单位商品价值量与社会劳动生产率成正比」在本书中**未出现**。
2. 第三章**没有**使用「供求规律」这一概念（相关内容以「供求机制」出现），也**没有**「价格围绕价值上下波动」「货币价值量与商品价格成反比」等旧版表述。
